    읽기 전용
    필터를 누르면 스크립트에서 해당 위치를 보여 줍니다 붙여 넣기 위치: 웹메일 설정 → 필터 → Add a Script

    만들어질 폴더

      파일을 넣으면 만들어질 폴더가 여기에 표시됩니다.

      웹메일에 붙여 넣기

      1. 웹메일 로그인 → 설정 → 필터
      2. 기존 스크립트가 있으면 먼저 복사해 따로 보관. 목록에서 로 켜진 스크립트를 눌러 열고, Simple 화면이면 창 아래 코드 아이콘(Use Custom User Script)을 눌러 나온 내용을 복사해 보관한 뒤 × 로 닫기. 웹메일 필터 화면에서 직접 만든 필터(Simple)를 쓰던 분은 4번에서 그 필터가 꺼집니다.
      3. Add a Script → 이름 입력(예: gmail-filters) → 코드 칸에 붙여 넣기 → 저장 → × 로 창 닫기
      4. 목록에서 새 스크립트 왼쪽 를 눌러 로 바꾸기(켜짐). 한 번에 하나만 켜지므로 기존 스크립트는 꺼집니다.

      주의사항

      • 활성 스크립트는 하나뿐 — 기존 스크립트나 필터가 있으면 합쳐야 함
      • 이미 받은 메일은 다시 분류되지 않음
      • 폴더로 간 메일은 POP3(Gmail 가져오기)로 넘어가지 않음
      • 단어 일부만 같아도 걸림 — '인증' 이 '인증서' 에도
      • 라벨과 달리 폴더마다 사본이 따로 — 읽음·삭제도 따로
      • 보관(받은편지함 건너뛰기) 필터에 걸린 메일은 스팸 표시가 있어도 그 폴더로 가고, 서버의 중복 메일 제거도 적용되지 않음
      • 스팸 안 보냄 필터에 걸린 메일은 받은편지함에 저장되고 서버의 스팸→정크 이동을 건너뜀. 서버의 스팸 판정·거부 자체를 해제하는 기능은 아님
      • 되돌리기: 보관해 둔 기존 스크립트를 다시 켜기(). 이미 폴더로 들어간 메일 사본은 직접 정리
